# Superstore Sales Performance Dashboard

## Project Overview
This Power BI dashboard analyzes Superstore sales performance across regions, categories, and customer segments. The dashboard provides insights into sales trends, profitability, and business performance to support data-driven decision-making.

## Objectives
- Track overall sales and profit performance
- Analyze monthly sales and profit trends
- Identify top-performing categories and regions
- Monitor profit margins and business growth
- Discover loss-making sub-categories

## KPIs Included
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin %

## Dashboard Features
- Interactive slicers and filters
- Sales and profit trend analysis
- Regional performance analysis
- Category and sub-category insights
- Custom tooltips and KPI cards

## Key Insights
- Technology category generates the highest revenue.
- Furniture shows lower profitability despite high sales.
- West region contributes the strongest profit performance.
- Some sub-categories negatively impact overall profit.

## Tools Used
- Power BI
- DAX
- Data Visualization
- Business Intelligence Techniques
